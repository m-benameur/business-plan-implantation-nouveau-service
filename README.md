# Business Plan — Implantation d'un nouveau service

## Présentation

Projet de création et d’analyse d’un business plan réalisé sous Excel dans le cadre de l’étude de l’implantation d’un nouveau service pour un acteur majeur de la restauration sur le marché lyonnais.

L'analyse repose sur plusieurs hypothèses afin d'évaluer la viabilité économique et financière du projet.

## Objectifs

- Étudier la viabilité économique du projet
- Construire plusieurs scénarios financiers
- Estimer le chiffre d'affaires prévisionnel
- Évaluer les charges et les besoins de financement
- Analyser la rentabilité du projet
- Évaluer l'impact des différentes hypothèses sur les résultats financiers

## Contenu

Le fichier Excel comprend notamment :

- Hypothèses financières
- Scénarios pessimiste, central et optimiste
- Prévisions de chiffre d'affaires
- Prévisions de charges
- Compte de résultat prévisionnel
- Plan de financement
- Plans de trésorerie
- Tableau d'amortissement
- Seuil de rentabilité
- Analyse de rentabilité

## Outil

- Microsoft Excel
